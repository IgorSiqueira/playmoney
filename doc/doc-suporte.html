Central de Suporte PlayMoney

Este guia cobre tudo que a equipe de suporte precisa para atender usuários, entender as regras do sistema e saber quando escalar para o time de administração.

🎮O que é o PlayMoney

O PlayMoney é uma plataforma de apostas em performance própria no Dota 2. O usuário vincula sua conta Steam, escolhe uma partida que vai jogar, aposta no próprio desempenho e recebe o resultado quando a partida termina.

O diferencial: o usuário não está apostando contra outras pessoas ou em times aleatórios — ele está apostando na própria habilidade. As odds são calculadas automaticamente com base no histórico das últimas 20 partidas do jogador.

Ambiente de demonstração
Atualmente o PlayMoney opera como plataforma de demonstração. Nenhuma transação financeira real é processada. Os depósitos e saques são simulados.

🗺️Jornada do Usuário

1
Cadastro (com convite)
O usuário acessa um link de convite e cria conta com e-mail e senha. Sem convite, não é possível se cadastrar (plataforma fechada).
2
Depósito inicial
Na página Carteira, o usuário deposita via PIX simulado. Depósito mínimo: R$ 10. Um bônus de boas-vindas (50% do depósito, até R$ 50) é creditado automaticamente se o depósito for ≥ R$ 20.
3
Vincular conta Steam
Na página Dota 2, o usuário informa o Steam ID. O sistema busca automaticamente o perfil e o histórico de partidas via OpenDota.
4
Fazer uma aposta
O usuário escolhe uma aposta simples (Vitória/Derrota) ou combo (Vitória + metas de kills, assists, GPM ou XPM). A odd é exibida antes da confirmação.
5
Jogar a partida
O usuário joga a partida no Dota 2 normalmente. O ID da partida é gerado ao final.
6
Liquidar a aposta
O usuário informa o ID da partida na plataforma. O sistema consulta a OpenDota, verifica o resultado e credita ou debita o saldo automaticamente.
7
Saque (opcional)
Com pelo menos 1 aposta liquidada, o usuário pode solicitar saque via PIX. Mínimo: R$ 20. O saldo bônus não é diretamente sacável.

Como as odds são calculadas

As odds são automáticas e personalizadas para cada jogador, calculadas com base nas últimas 20 partidas no Dota 2. São considerados: taxa de vitórias recente, sequência de vitórias/derrotas, KDA médio, rank, tendência de GPM e XPM. Há uma margem da casa de 8%.

Usuário diz que a odd estava diferente quando apostou
As odds são calculadas no momento da criação da aposta e ficam registradas na aposta — não mudam depois. Se o usuário está comparando com odds exibidas mais tarde, elas podem ter mudado porque novas partidas foram jogadas.

Liquidação da aposta

O usuário informa o ID da partida na página "Meus Jogos". O sistema consulta a OpenDota automaticamente. Se a API estiver indisponível (manutenção ou instabilidade), o admin pode fazer override manual do resultado.

🔗Sistema de Convites

O PlayMoney é uma plataforma fechada por convite. Apenas usuários autorizados pelo admin podem gerar links de convite. Cada usuário tem um único link de convite. O link pode ser compartilhado com múltiplas pessoas.

❓Problemas Frequentes

Não consigo vincular minha conta Steam

Causas comuns: (1) Perfil privado — o perfil precisa ser público no Steam para a OpenDota conseguir ler. (2) Steam ID incorreto — orientar o usuário a usar o ID numérico do perfil (não o vanity URL). (3) Outra conta na plataforma já usa esse Steam ID — um mesmo Steam ID não pode ser vinculado a duas contas.

Apostei mas a partida não foi encontrada

A OpenDota demora alguns minutos para indexar uma partida após o fim. Orientar o usuário a aguardar 5 a 10 minutos e tentar novamente. Se após 30 minutos ainda não funcionar, o admin pode realizar o override manual com o resultado correto.

Minha aposta foi para resultado errado

Verificar: (1) se o Match ID informado pertence de fato a uma partida do usuário; (2) se o resultado da OpenDota está correto (acesse opendota.com e verifique o match). Se houver discrepância, o admin pode fazer override. Registre o caso com print da tela do usuário e o Match ID.

Não recebi o bônus de boas-vindas

Requisitos: primeiro depósito deve ser de R$ 20 ou mais. O bônus é creditado apenas uma vez por conta. Se o usuário depositou menos de R$ 20 no primeiro depósito, o bônus não é retroativo — ele precisaria depositar mais (somando ao que já tem) e o sistema verificará o valor do primeiro depósito, não de depósitos subsequentes. Esclareça e, se necessário, solicite ao admin ajuste manual.

Tentei depositar mas recebi erro de limite

O usuário pode ter atingido o limite diário de R$ 2.000 ou ter um limite personalizado configurado pelo admin. Consulte o painel do usuário para ver o depositLimit configurado. Informe o limite atual e quando ele é resetado (meia-noite).

Não consigo sacar — erro "nenhuma aposta liquidada"

Essa é uma regra de segurança do sistema: é necessário ter pelo menos uma aposta com resultado (ganhou ou perdeu) antes de sacar pela primeira vez. Oriente o usuário a jogar pelo menos uma partida e liquidar a aposta antes de solicitar o saque.

A página diz que a plataforma está em manutenção

O admin ativou o modo de manutenção. Geralmente há um banner com previsão de retorno. Consulte a equipe de TI ou admin para saber quando será liberado. Informe ao usuário o horário previsto caso tenha essa informação.

O usuário suspeita de outra conta usando seu Steam ID

Solicitar ao admin verificação do GameProfile com aquele externalId. Se confirmado, o admin pode reatribuir o Steam ID ao usuário legítimo usando o painel de troca de conta Steam.

💬Respostas Prontas

Partida não encontrada

Template
Olá! A OpenDota, sistema que usamos para verificar os resultados das partidas, pode demorar alguns minutinhos para indexar uma partida recente. Aguarde cerca de 5 a 10 minutos e tente informar o Match ID novamente. Se o problema persistir após esse tempo, entre em contato novamente com o Match ID e eu verifico para você!

Saque bloqueado (sem apostas liquidadas)

Template
Para realizar o primeiro saque, é necessário ter pelo menos uma aposta concluída — seja ganho ou perda. Isso faz parte das nossas regras de segurança para evitar fraudes. Jogue uma partida, informe o Match ID na plataforma e, após a liquidação, você poderá solicitar o saque normalmente!

Bônus não creditado

Template
O bônus de boas-vindas é creditado automaticamente quando o primeiro depósito é de R$ 20 ou mais. Se o seu primeiro depósito foi menor que esse valor, o bônus não é aplicado retroativamente. Podemos verificar o histórico da sua conta e, se necessário, avaliar um ajuste manual com nossa equipe.

⚙️Suporte vs. Admin

Suporte pode resolver
  • Orientar sobre regras de saque, depósito e bônus
  • Explicar por que a odd foi aquela
  • Confirmar o status de uma aposta
  • Orientar sobre tempo de indexação de partidas
  • Explicar limite de depósito diário
  • Confirmar que o link de convite está funcionando
Precisa escalar ao Admin
  • Override manual de resultado de aposta
  • Cancelamento de aposta com estorno
  • Ajuste de saldo por erro do sistema
  • Suspender ou liberar usuário suspeito
  • Habilitar convites para um usuário
  • Trocar Steam ID vinculado à conta
  • Bloquear ou liberar depósitos do usuário

Sinais de risco automáticos
O sistema detecta automaticamente comportamentos suspeitos: apostas em partidas com aliados recorrentes (PARTY_RECURRENCE), precisão de apostas acima do esperado (BET_ACCURACY), adversários fracos (WEAK_ENEMIES) e pico abrupto na taxa de vitórias (WIN_RATE_SPIKE). O admin deve revisar e decidir se suspende o usuário.
